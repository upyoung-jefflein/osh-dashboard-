裁罰基準參考（以臺北市政府裁罰基準為例，115年7月1日修正版）

違反情形法條依據裁罰基準
危害性化學品洩漏或引起火災、爆炸致發生重大職業災害（甲類事業）第42條第1項第一次100萬元，按次累加100萬元，最高累加至300萬元
同上情形（乙類事業，115年7月1日後標準，較原30萬元提高）第42條第1項第一次50萬元，按次累加50萬元，最高累加至300萬元
一般違反職業安全衛生法規定（未致重大職災之常見違規）依違反條款而定每項最高30萬元，得按次處罰；有立即發生危險之虞者，得令停工

裁罰基準由各地方政府勞工主管機關個別訂定並執行，各縣市金額可能略有差異，上表以臺北市政府公告版本為例，實際處分請以受處分之縣市公告基準及個案裁量為準。

常用名詞與作業安全標準：以局限空間為例

法定定義
依職業安全衛生設施規則第19條之1，指非供勞工在其內部從事經常性作業，勞工進出方法受限制，且無法以自然通風來維持充分、清淨空氣之空間。
氣體濃度標準
氧氣濃度須保持在18%以上；一氧化碳濃度須藉換氣維持在35ppm以下；硫化氫濃度須藉換氣維持在10ppm以下（勞動部職業安全衛生署宣導標準）
主要相關法規
職業安全衛生設施規則、缺氧症預防規則、營造安全衛生設施標準（隧道、沉箱等作業）
來源：職業安全衛生設施規則、勞動部職業安全衛生署宣導資料
